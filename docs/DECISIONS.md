# Decisions and differences from the build plan

Rule 9: where the plan and the current SDK/API docs disagree, follow the docs and record it here.

| Phase | Plan said                                                                        | What we did                                                                                                                                                                                                                                         | Why                                                                                                                                                                                                            |
| ----- | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1     | Server deps `server`, `node`, `express`, `ext-apps`                              | Also `@modelcontextprotocol/client@^2`                                                                                                                                                                                                              | Required peer of `ext-apps` 2.x (ext-apps README).                                                                                                                                                             |
| 1     | —                                                                                | `createMcpExpressApp({ host: "0.0.0.0" })`                                                                                                                                                                                                          | Default binds 127.0.0.1 with Host-header checks; a public server must accept its public hostname. The SDK logs a warning about DNS-rebinding protection; acceptable for a read-only, no-auth server.           |
| 1     | —                                                                                | Server bundled with esbuild to `server/dist/index.js`                                                                                                                                                                                               | Inlines the TypeScript-only `@weather/shared` workspace; npm deps stay external.                                                                                                                               |
| 1     | `GET /mcp`                                                                       | 405                                                                                                                                                                                                                                                 | Stateless Streamable HTTP has no server-initiated stream or sessions.                                                                                                                                          |
| 2     | Hourly detail "adds `hourly=` with `start_date`/`end_date`" to the forecast call | Separate request for hourly                                                                                                                                                                                                                         | Open-Meteo returns 400: "Parameter 'forecast_days' is mutually exclusive with 'start_date' and 'end_date'".                                                                                                    |
| 2     | Ambiguous if the top two geocoding results are in different countries/regions    | Same, unless the top result's population is ≥ 5× the runner-up's (or the runner-up has none)                                                                                                                                                        | Otherwise "Jaipur" (3M, India) is ambiguous with a Bangladeshi village. With 5×: Jaipur, Delhi, London, Paris, Portland resolve; Springfield, Cambridge, San Jose, Hyderabad ask.                              |
| 2     | —                                                                                | `", Country/Region"` qualifier filters geocoding results                                                                                                                                                                                            | Lets "Noida, India" / "Springfield, Illinois" resolve deterministically.                                                                                                                                       |
| 2     | `weatherCodes.ts`, `aqi.ts` in `server/src/openmeteo/`                           | Tables live in `shared/` and are re-exported there                                                                                                                                                                                                  | Views need the same icons and AQI bands.                                                                                                                                                                       |
| 3     | zod errors → `INVALID_INPUT` ToolError                                           | Tools advertise the full zod JSON Schema but validate inside the handler                                                                                                                                                                            | The SDK's own validation returns plain text with no `structuredContent`.                                                                                                                                       |
| 3     | —                                                                                | No `outputSchema` declared                                                                                                                                                                                                                          | Error results carry `ToolError` in `structuredContent`; clients that validate it against a success schema would flag them. Outputs are validated against zod mirrors (`shared/schemas.ts`) in tests and views. |
| 3     | Error text "one line"                                                            | Error texts have no attribution line                                                                                                                                                                                                                | They contain no weather data; rule 5 applies to data outputs.                                                                                                                                                  |
| 3     | `get_historical_weather` "not in the future"                                     | `end_date` ≤ today in UTC+14; days the archive hasn't filled yet are skipped; an all-empty range → `INVALID_INPUT`                                                                                                                                  | Archive lags a few days; local "today" is unknown before the request.                                                                                                                                          |
| 3     | Open-Meteo 4xx                                                                   | Mapped to `INVALID_INPUT` with a generic message                                                                                                                                                                                                    | Rule 6: never pass upstream reasons to the client (they're logged).                                                                                                                                            |
| 4     | "strictest content-security settings"                                            | `_meta.ui` on each resource (listing and content item): empty `connectDomains`, `resourceDomains`, `frameDomains`, `baseUriDomains`; no `permissions`; `prefersBorder: true`                                                                        | Empty/omitted CSP lists are the spec's secure default; declared explicitly so reviewers see it.                                                                                                                |
| 4     | —                                                                                | `VIEWS_DIST_DIR` env overrides where built views are read from                                                                                                                                                                                      | Tests use stub HTML; production reads `views/dist`.                                                                                                                                                            |
| 4     | —                                                                                | Views built at ~456 KB each (React + ext-apps + zod)                                                                                                                                                                                                | Over the 300 KB target; addressed in Phase 8.                                                                                                                                                                  |
| 5     | "validates structuredContent against the matching contract type"                 | Views validate with zod mirrors in `shared/schemas.ts`; invalid data → `UPSTREAM_UNAVAILABLE`-style error state                                                                                                                                     | TypeScript types alone can't validate at runtime.                                                                                                                                                              |
| 5     | Theme via host-style helpers                                                     | `useHostStyles` + `--wx-*` tokens that fall back from host variables (`--color-*`) to `light-dark()` colours                                                                                                                                        | `light-dark()` follows `color-scheme`, which `useHostStyles` sets from the host theme, else `prefers-color-scheme`.                                                                                            |
| 5     | `Tabs`                                                                           | Segmented buttons with `aria-pressed`                                                                                                                                                                                                               | Each option triggers a tool call (no tab panels), so pressed buttons are the accurate ARIA pattern.                                                                                                            |
| 5     | `npm run preview:views`                                                          | Vite dev page `views/preview.html` (excluded from the build) rendering fixtures in light and dark                                                                                                                                                   | Fixtures are real tool outputs captured by `server/scripts/gen-view-fixtures.ts`.                                                                                                                              |
| 6     | Views re-call tools by coordinates                                               | The view keeps the place name it already knows (or the alternative the user picked) when the result for the same coordinates comes back coordinate-named                                                                                            | Otherwise the header turns into "26.92, 75.79" after the first click.                                                                                                                                          |
| 6     | —                                                                                | Chart drawn at the measured container width (ResizeObserver), weekday labels thinned to ≥ 40 px each                                                                                                                                                | Scaling a fixed viewBox would shrink 13 px labels below the 13 px minimum at 320 px.                                                                                                                           |
| 6     | —                                                                                | Server re-reads built views when their mtime changes                                                                                                                                                                                                | So `npm run dev` rebuilds show up without restarting.                                                                                                                                                          |
| 7     | Air quality "Next 3 days" button                                                 | `Today` / `Next 3 days` segmented control (UI table says "Today / next 3 days switch")                                                                                                                                                              | Covers both wordings; chips appear only for the multi-day result.                                                                                                                                              |
| 7     | —                                                                                | The hook remembers the latest tool input (`ontoolinput`)                                                                                                                                                                                            | Lets the history view re-run the user's dates when they pick an alternative place after `AMBIGUOUS_LOCATION`.                                                                                                  |
| 7     | —                                                                                | History y-axis padding sized to its longest tick label                                                                                                                                                                                              | Labels like "60 mm" were clipped at 320 px.                                                                                                                                                                    |
| 8     | Rate limit "per IP"                                                              | In-memory fixed window keyed by `req.ip` (`TRUST_PROXY` hops), bounded to 10,000 keys; IPs are never logged                                                                                                                                         | Rule 10 (no tracking).                                                                                                                                                                                         |
| 8     | Tool-call logs include "cache hit or miss"                                       | `hit` / `miss` / `partial` / `none`, via AsyncLocalStorage per call                                                                                                                                                                                 | A call can need both a cached geocode and a fresh forecast.                                                                                                                                                    |
| 8     | Daily limit "serve cached data only"                                             | Checked before every real request; cache lookups happen first; no retries when out of budget                                                                                                                                                        | Matches the plan; cache misses return `UPSTREAM_UNAVAILABLE`.                                                                                                                                                  |
| 8     | `Cache-Control: no-store` on `/mcp`                                              | The SDK's SSE transport sets `no-cache, no-transform` on event-stream responses                                                                                                                                                                     | Equivalent for this purpose.                                                                                                                                                                                   |
| 8     | View size under 300 KB                                                           | Not met (~470 KB, ~134 KB gzipped); reported in `docs/SECURITY.md`                                                                                                                                                                                  | Mostly the SDK's own `zod` and client; needs your acceptance (A4).                                                                                                                                             |
| 9     | `docker build` / `docker run` check                                              | **Not run**: Docker is not installed on this machine. The runtime stage was simulated instead (same file layout, `npm ci --omit=dev --workspace server`, `node server/dist/index.js`): health, tools, four resources and a live forecast all worked | Please run `docker build -t open-meteo-weather-mcp . && docker run --rm -p 3001:3001 open-meteo-weather-mcp` once before deploying.                                                                            |
| 9     | Image contains only production dependencies                                      | `react` / `react-dom` are still installed (peer dependencies of `ext-apps`); the server never loads them                                                                                                                                            | Harmless; only the `/server` entry of ext-apps is used.                                                                                                                                                        |
| 9     | Render free tier                                                                 | `render.yaml` uses `plan: free`, `autoDeployTrigger: commit`, `TRUST_PROXY=1`; no `PORT` (Render provides it, default 10000)                                                                                                                        | Verified against Render's Blueprint, web-service, free-tier and custom-domain docs.                                                                                                                            |
